# Physics Draw — 물리 기반 드로잉 퍼즐

선과 도형을 직접 그려 물리 오브젝트를 만들고, 중력과 충돌을 이용해 공을 목표 컵까지 보내는 브라우저 퍼즐 게임입니다. 16개의 스테이지에서 경사로·지렛대·바운서·특수 중력 구역 등을 활용하고, 별과 잉크 사용량을 기준으로 클리어를 도전할 수 있습니다.

## 주요 기능

- **직접 그리는 물리 오브젝트**: 자유 낙하, 고정 지지대, 회전 힌지 도구로 선을 그려 경사로·다리·추 등을 만듭니다.
- **물리 퍼즐**: 공을 목표 컵에 넣고, 스테이지별 별을 수집합니다. 16개 기본 레벨에는 쌍둥이 구슬, 탄성 패드, 반중력·바람 구역, 스위치 게이트 등의 기믹이 있습니다.
- **잉크 예산과 별점**: 그린 선의 길이가 잉크 사용량에 반영됩니다. 적은 잉크 사용과 별 수집으로 더 높은 별점을 노려보세요.
- **샌드박스**: 공, 목표 컵, 탄성 패드, 별, 반중력 구역을 배치하고 직접 만든 레벨을 JSON으로 가져오거나 내보낼 수 있습니다.
- **진행 상황 저장**: 해금 상태, 완료 여부, 별점과 최고 기록을 브라우저 `localStorage`에 저장합니다.
- **조작 편의 기능**: 실행/일시정지, 시뮬레이션 속도 조절, 힌트, 실행 취소, 지우개, 효과음 설정을 제공합니다.

## 시작하기

필요한 환경: Node.js와 패키지 매니저(Bun 권장). 저장소에는 `bun.lock`이 포함되어 있습니다.

```bash
# 저장소 복제 후 프로젝트 디렉터리에서
bun install
bun run dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 실행됩니다. npm을 사용한다면 다음과 같이 실행할 수 있습니다.

```bash
npm install
npm run dev
```

## 스크립트

| 명령 | 설명 |
| --- | --- |
| `bun run dev` | Vite 개발 서버를 3000 포트에서 실행 |
| `bun run build` | 프로덕션 빌드를 `dist/`에 생성 |
| `bun run preview` | 프로덕션 빌드 미리보기 |
| `bun run lint` | TypeScript 타입 검사 (`tsc --noEmit`) |
| `bun run clean` | `dist/`와 `server.js` 제거 |

테스트 실행 스크립트는 현재 `package.json`에 정의되어 있지 않습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 또는 터치 드래그 | 선택한 도구로 그리기 |
| `Space` | 물리 시뮬레이션 재생/일시정지 |
| `Ctrl+Z` 또는 `⌘Z` | 마지막으로 그린 선 실행 취소 |
| `R` | 현재 레벨 초기화 |
| `H` | 힌트 가이드 표시/숨기기 |

- **자유 낙하**: 움직이는 물리 선을 그립니다.
- **고정 지지대**: 움직이지 않는 플랫폼이나 경사로를 만듭니다.
- **회전 힌지**: 선의 시작점에 회전축을 둡니다.
- **지우개**: 그린 오브젝트를 지우고 해당 선의 잉크를 돌려받습니다.

## 프로젝트 구조

```text
src/
  App.tsx                  게임 상태, 레벨 진행, UI 통합
  main.tsx                 React 앱 진입점
  types.ts                 레벨·오브젝트·진행 상황 타입
  index.css                Tailwind와 전역 스타일
  components/              캔버스, HUD, 레벨 선택·도움말·샌드박스 UI
  game/
    levels.ts              16개 기본 레벨과 캔버스 크기
    physics.ts             Matter.js 물리 엔진 및 충돌/목표 판정
    sound.ts               Web Audio API 효과음
index.html                 앱 HTML 진입점
vite.config.ts             Vite, React, Tailwind 설정
```

`GameCanvas`는 1000×650 논리 좌표 캔버스에서 포인터 입력을 받고 프레임마다 `PhysicsEngine`을 업데이트해 게임을 그립니다. `physics.ts`는 Matter.js로 레벨 오브젝트와 사용자가 그린 선을 강체로 구성하며 별 수집 및 목표 컵 도달 이벤트를 처리합니다. `App.tsx`가 해당 이벤트를 UI와 연결하고 스테이지 진행을 브라우저 저장소에 기록합니다.

## 기술 스택

- **언어**: TypeScript
- **UI / 런타임**: React 19, Vite 8
- **물리 엔진**: Matter.js
- **스타일**: Tailwind CSS 4
- **기타**: Lucide React 아이콘, canvas-confetti, Web Audio API 효과음

## 설정 참고

`.env.example`에는 Google AI Studio 연동용 `GEMINI_API_KEY`와 호스팅 URL용 `APP_URL` 예시가 있습니다. AI Studio 환경은 이 값을 런타임에 주입하도록 설명되어 있습니다. 현재 게임의 레벨·물리 플레이 경로에서는 해당 값을 직접 사용하지 않습니다.
